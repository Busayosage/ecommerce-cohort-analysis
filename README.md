# 🛒 E-commerce Cohort Analysis

## 📊 Project Overview
This project analyzes customer retention and behavior over time in an e-commerce platform using **cohort analysis**.  
The goal is to identify how user engagement and repeat purchases evolve weekly and monthly after first purchase.

## 🎯 Objectives
- Identify retention trends and customer churn.  
- Measure how long customers remain active.  
- Compare retention between different acquisition cohorts.  

## 🧠 Data Description
The dataset includes:
- `Dataset_ecommerce.csv`: Customer purchase transactions  
- `Historical Product Demand.csv`: Product demand trends  
- `inventory_dataset.csv`: Inventory and stock data  

## 🧮 Methodology
1. Data Cleaning & Preprocessing  
2. Creating Cohorts by Customer Signup/Purchase Date  
3. Calculating Retention Rates  
4. Visualizing Cohort Retention Heatmaps  

## 📈 Tools Used
- Python (Pandas, NumPy)  
- Matplotlib & Seaborn for Visualization  
- JupyterLab  
- Git & GitHub for Version Control
